# Things to Explore in Rwanda

## Project Title

Things to Explore in Rwanda

## Short Description

A simple interactive web page showcasing Rwandan attractions with DOM-based navigation, list management, search filtering, and card displays.

## Features Implemented

- Responsive navigation menu with a mobile hamburger toggle
- Dropdown menu for Services
- Dark mode toggle using DOM class manipulation
- Dynamic text change button
- Addable/removable custom list items
- Search filter that hides/shows attraction list items in real time
- Attraction cards with images and add buttons
- Tailwind CSS styling for layout and responsiveness

## What This Project Demonstrates

This project demonstrates basic DOM manipulation and event handling in JavaScript, including:

- selecting and updating elements
- handling click and input events
- toggling CSS classes for theme and layout changes
- dynamically creating and removing list items
- filtering content based on user input
